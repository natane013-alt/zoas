# 🎉 Página Interativa – "Pergunta dos Botões" 😂

Este projeto é uma página divertida feita com **HTML, CSS e JavaScript**, onde o usuário recebe uma pergunta engraçada e dois botões:
- ✔ **SIM**
- ❌ **NÃO** (mas ele foge do cursor e explode! 💥)

Uma brincadeira leve para mandar para amigos e ver a reação deles.

---

## 🧩 Funcionalidades

- 😆 Botão **NÃO** corre pela tela para evitar ser clicado
- 💥 Depois de algumas tentativas, o botão **NÃO explode**
- ✔ Botão **SIM** funciona normalmente
- 🎨 Estilo simples e limpo
- 📱 Totalmente responsivo

---

## 🚀 Como usar

1. Abra a página pelo GitHub Pages ou baixe o arquivo `index.html`.
2. Envie o link para seus amigos.
3. Divirta-se vendo eles tentando clicar no **NÃO** 🤣
